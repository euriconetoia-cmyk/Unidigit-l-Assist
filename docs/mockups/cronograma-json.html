COMO APLICAR

O editor do Moodle protege o texto

O editor refaz o campo ao salvar, então a extensão não consegue “digitar” dentro dele com segurança.

1Você clica em Abrir a edição do texto; a extensão já copiou o HTML atualizado.
2No editor, abra Ferramentas → Código-fonte (ou o botão </>), apague tudo e cole.
3Clique em Salvar. A extensão relê o texto e confere cada data (conferido / diferente).
Alternativa mais simples: só mostrar “antes → depois” e você edita as datas à mão. Você escolhe na configuração.
